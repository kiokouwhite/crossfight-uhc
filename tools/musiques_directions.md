# Musiques de combat : la direction de chaque licence

Chaque licence a sa sonorite ; la musique d'un combat entre deux equipes (`resourcepack/music.txt`, une piste par
paire) melange les deux, comme un vrai morceau qui fusionne les deux styles (pas deux pistes l'une sur l'autre).

| Licence | Sonorite | Morceau de reference |
|---|---|---|
| Fire Emblem | royal | a choisir |
| RWBY | jazzy | [Showtime! (Jens Vide)](https://jens-vide.itch.io/showtime) : jazz d'action, cuivres heroiques |
| SNK | guerrier | a choisir |
| Unordinary | phonk | a choisir |
| Valorant | techno, boombass | a choisir |
| Earth Delta | epique | a choisir |
| Gunvolt | techno moderne petillante | a choisir |
| Shoja's Memories | goofy, mi-serieux mi-epique | a choisir |
| Bloody Snow | hardcore breakcore | a choisir |
