# Arlo

Voie de la Destruction

## Pouvoirs

### Aura

(Activable) La jauge d'Arlo : 100 points, +3 par seconde. Les barrières et les cages la consomment.

### Barrière

(Activable) Un disque doré qui suit Arlo : tant qu'il est actif (5 d'Aura par seconde), Arlo ne prend que la moitié des dégâts.

{% file src="../../../videos/arlo/arlo_barriere.mp4" %}
Barrière en jeu
{% endfile %}

[▶ Voir la vidéo](https://github.com/kiokouwhite/crossfight-uhc/raw/main/guide/videos/arlo/arlo_barriere.mp4)

### Barrière Ultime

(Activable) Une bulle dorée autour d'Arlo : tant qu'elle est active (10 d'Aura par seconde), il ne prend aucun dégât et celui qui tente de le blesser les prend à sa place.

{% file src="../../../videos/arlo/arlo_barriere_ultime.mp4" %}
Barrière Ultime en jeu
{% endfile %}

[▶ Voir la vidéo](https://github.com/kiokouwhite/crossfight-uhc/raw/main/guide/videos/arlo/arlo_barriere_ultime.mp4)

### Enfermement

(Actif) Clic droit vers un adversaire : il est enfermé dans une bulle dorée infranchissable (5 d'Aura par seconde). Accroupi + clic droit sur lui : relâche. Plusieurs bulles possibles.

{% file src="../../../videos/arlo/arlo_enfermement.mp4" %}
Enfermement en jeu
{% endfile %}

[▶ Voir la vidéo](https://github.com/kiokouwhite/crossfight-uhc/raw/main/guide/videos/arlo/arlo_enfermement.mp4)

### Étouffement

(Actif) Clic droit vers un adversaire : une toute petite bulle le plaque au sol, il perd 1 cœur par seconde (10 d'Aura par seconde). Accroupi + clic droit sur lui : relâche. Plusieurs bulles possibles.

### Bulle géante
